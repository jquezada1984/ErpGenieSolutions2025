15. CAMBIO MASIVO
------------------------------------------------------------

Tablas public.cambio_masivo_stock / _detalle
Constraints confirmados:
  PK cabecera/detalle
  UNIQUE (id_empresa, id_origen)
  UNIQUE (id_cambio_masivo_stock, id_item)
  CHECK tipo IN (POSITIVO, NEGATIVO)
  CHECK cantidad > 0
  FK detalle → cabecera ON DELETE RESTRICT

Índice:
  uq_mov_inv_cambio_masivo_stock_idempotencia
  (id_empresa, id_origen) WHERE modulo_origen='CAMBIO_MASIVO_STOCK'

Writer:
  lock conjunto ORDER BY id_stock_producto_almacen FOR UPDATE
  validación negativos tras locks, antes de UPDATE
  1 TX / 1 commit / rollback total
  movimientos AJUSTE_* + CAMBIO_MASIVO_STOCK
  id_origen movimiento = PK detalle
  NO usa modulo AJUSTE_STOCK para el lote

E2E: backend 12B.3 GO, atomicidad negativa 12B.3.1 GO,
     Gateway 12C.1 GO, UI 12D.1 evidencia BD presente.
