  NO verifica JWT localmente.
  NO comparte JWT_SECRET.

Helper:
  authenticatedWriteContext(req, body)
  Archivo: gateway-api/src/utils/requestContext.js
  Uso limitado a: crearStockInicial

Trust boundary STOCK INICIAL:

  NO CONFIABLE:
    request.headers['x-user-id'] (cliente / navegador)

  CONFIABLE:
    me.user.id_usuario

Downstream:

  X-User-Id     = me.user.id_usuario
  Authorization = Bearer original (reenviado)
  X-Company-Id:
    EMPRESA → me.user.id_empresa
    GLOBAL  → tras autenticar:
              body.id_empresa
              → header X-Company-Id
              → me.user.id_empresa

Helpers legacy (ctxHeaders / getUsuarioScope):
  INTACTOS — no forman parte del flujo STOCK INICIAL.


7. FAIL-CLOSED
--------------------------------------------------------------------------------
Sin Authorization Bearer válido estructuralmente:
  → 401
  → NO llamada a AlmacenPython

HTTP 401 / 403 explícitos desde InicioNestJs o GraphQL
(con evidencia inequívoca: codes UNAUTHENTICATED / UNAUTHORIZED /
FORBIDDEN o statusCode 401/403):
  → 401 / 403
  → FAIL CLOSED

GraphQL errors internos / indeterminados:
  → 500
  → FAIL CLOSED

me.user null / id_usuario ausente / scope_acceso ausente /
scope desconocido / empresa no resoluble:
  → 500 (contexto incompleto)
  → FAIL CLOSED

Auth service down / timeout / transporte:
  → 500
  → FAIL CLOSED

NO fallback a:
  X-User-Id del cliente
  body.id_empresa como sustituto de identidad

Prueba dinámica observada (4F.2):

  Se ejecutaron accidentalmente 2 POST vía Gateway
  sin ERP_ACCESS_TOKEN disponible.
