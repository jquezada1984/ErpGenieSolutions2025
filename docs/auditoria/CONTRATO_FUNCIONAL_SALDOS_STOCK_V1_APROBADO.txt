5. STOCK_FISICO
--------------------------------------------------------------------------------
Cantidad real físicamente existente del item dentro de un almacén.


6. STOCK_RESERVADO
--------------------------------------------------------------------------------
Cantidad del stock físico comprometida para una operación y que no
puede utilizarse como stock libre.

v1: no hay writer de reserva; en STOCK INICIAL = 0.


7. STOCK_DISPONIBLE
--------------------------------------------------------------------------------
Cantidad física existente que todavía puede utilizarse y que no está
reservada.

Columna PERSISTIDA. No se elimina. No se convierte en generated.
Los writers deben mantenerla sincronizada.


8. STOCK_VIRTUAL
--------------------------------------------------------------------------------
Semántica avanzada: PENDIENTE DE DEFINICIÓN.

Mientras no exista dominio implementado (compras pendientes, tránsito,
proyecciones, etc.):

  stock_virtual = 0

NO participa en la fórmula de stock_disponible v1.


9. FÓRMULA DE DISPONIBLE (v1)
--------------------------------------------------------------------------------
stock_disponible = stock_fisico - stock_reservado

NO:
  fisico - reservado + virtual
  fisico + virtual
  otra fórmula sin contrato posterior.


10. REGLA STOCK INICIAL
--------------------------------------------------------------------------------
Para cantidad inicial Q:

  stock_fisico      = Q
  stock_reservado   = 0
  stock_disponible  = Q
  stock_virtual     = 0

Porque Q - 0 = Q.

Ejemplo Q = 100:
  fisico 100, reservado 0, disponible 100, virtual 0.

El writer ACTUAL aún persiste disponible vía DEFAULT 0.
Este contrato APRUEBA el comportamiento esperado; NO lo implementa.
La alineación del INSERT queda para fase 6D (autorización expresa).


11. INVARIANTES FUNCIONALES v1
--------------------------------------------------------------------------------
 1. stock_fisico >= 0
 2. stock_reservado >= 0
 3. stock_disponible >= 0
 4. stock_reservado <= stock_fisico
 5. stock_disponible = stock_fisico - stock_reservado
 6. No reservar más de stock_disponible.
 7. Una salida libre no puede superar stock_disponible.
 8. Una salida reservada no puede superar la reserva correspondiente.
 9. Cambio de saldo + movimiento_inventario en la misma transacción.
10. Error: rollback completo.
11. Replay idempotente: no vuelve a modificar saldos.

Reglas 6–8: documentadas para FUTUROS writers. NO implementadas en 6C.
Reglas 9–11: ya aplicadas en STOCK INICIAL v1.


12. OPERACIONES FUTURAS (NO IMPLEMENTAR EN 6C)
--------------------------------------------------------------------------------
RESERVA Q:           fisico sin cambio; reservado +Q; disponible -Q
LIBERACIÓN Q:        fisico sin cambio; reservado -Q; disponible +Q
SALIDA LIBRE Q:      fisico -Q; reservado sin cambio; disponible -Q
SALIDA RESERVADA Q:  fisico -Q; reservado -Q; disponible sin cambio
AJUSTE POSITIVO Q:   fisico +Q; disponible +Q
AJUSTE NEGATIVO Q:   fisico -Q; disponible -Q

TRANSFERENCIA INMEDIATA A → B, cantidad Q:
  origen:  fisico -Q, disponible -Q
  destino: fisico +Q, disponible +Q
  reservado: sin cambio salvo diseño futuro
  virtual: NO usar todavía

Estados SOLICITADA / EN_TRANSITO / RECIBIDA: PENDIENTES.
No resolverlas con stock_virtual en v1.

--------------------------------------------------------------------------------

Fallo → rollback; sin saldos a medias.
